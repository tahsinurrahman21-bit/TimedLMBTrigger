# Changelog

All notable changes to this project are listed here. Versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-25

First public release.

- Schedule one left mouse click or one Enter key press at a chosen local time.
- Click at the current cursor position or at saved screen coordinates.
- Confirmation before arming, live countdown, and a 10-second test mode.
- Emergency cancel with **Ctrl+Alt+X**; capture a click position with **Ctrl+Alt+S**.
- Optional "keep PC awake while armed".
- Missed-trigger detection (more than 5 seconds late), single-instance protection,
  and safety checks for locked desktops, held keys and self-targeting.
- Local settings and a rotating activity log; no network access or telemetry.
- Standalone Windows executable built with PyInstaller.
